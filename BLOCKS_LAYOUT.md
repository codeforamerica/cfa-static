# Design System Reference

The canonical references now live alongside the site-builder skill:

- [Block Reference](skills/cfa-static-site-builder/references/blocks.md): generated full field schemas, nested requirements, canonical YAML examples, resolved source paths, CMS availability, container widths, and column/sidebar compatibility.
- [Layouts](skills/cfa-static-site-builder/references/layouts.md): authored rendering architecture, multi-column matching, site-wide sidebar behavior, supporting components, and styling guidance.

`BLOCKS_LAYOUT.md` remains as a hand-authored navigation page for existing consumers. Only the block reference is generated by `npm run generate-blocks-reference`; edit layout guidance directly in `layouts.md`.

Use `npm run generate-references` to refresh all generated references and CMS artifacts together.
